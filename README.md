## DailyTools
A simple website that collects everyday tools in one place. Users can check prayer times, currency exchange, and worldwide weather. No account is needed. It is free and mobile-friendly.

 Features
- Multiple tools: Prayer times, currency converter, global weather (more soon).
- No signup: Use all tools without creating an account.
- Responsive: Works on mobile, tablet, and desktop.
- Fast & simple: Clean UI and quick results.


  Tech Stack
- Frontend: HTML, CSS, JavaScript (Vanilla)
- APIs:
  - Weather
  - Prayer Times
